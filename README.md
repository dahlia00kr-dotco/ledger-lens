# 전표 검토 툴

월 결산 때 전표를 검토하면서 **반복거래 누락·중복**, **거래처별로 처음 보는 계정 처리**, **결산전표 누락·금액 변동**을 찾아내는 웹 도구입니다.
검토하면서 내린 판단(정상패턴 등록 / 이번만 허용 / 이슈)이 패턴DB에 쌓이기 때문에, 쓸수록 검토 정확도가 올라갑니다.

> 모든 데이터는 브라우저 안에서만 처리됩니다. 업로드한 전표 엑셀과 패턴DB는 서버로 전송되지 않습니다.
> (`vercel.json`의 CSP에서 외부로 데이터를 보내는 요청을 막아 두었습니다.)

## 샘플 데이터로 체험하기

배포된 사이트는 **체험판**입니다. 접속하면 가상의 제조회사 2025년 전표(1,913라인)가 자동으로 불러와지고, 1~11월 이력으로 정상패턴이 수집된 상태에서 시작합니다. 내 파일 업로드와 패턴DB 파일 저장은 숨겨져 있고, 판단 결과는 저장되지 않습니다(새로고침하면 처음 상태로 돌아갑니다).
실무용으로 쓰려면 `assets/app.js`의 `const DEMO=true`를 `false`로 바꾸면 됩니다. 그러면 파일 업로드, 패턴DB 저장, 브라우저 자동 저장이 다시 켜집니다.
 회사명·거래처명·금액은 모두 가상입니다.
검토월은 2025-12이며, 12월에는 아래 이슈를 일부러 심어 두었습니다.

| 심어 둔 이슈 | 도구에서 보이는 곳 |
|---|---|
| 커피머신 렌탈료 누락 | 고정전표 체크 · 누락 |
| 경비보안 월정료 2번 입력 | 요약 · 동일 전표 중복 의심 / 고정거래 · 건수↑ |
| 세무자문 수수료를 복리후생비로 처리, 사무용품을 기업업무추진비로 처리 | 신규 계정패턴 · 기존 거래처·새 계정 |
| 비품 감가상각비 누락, 시설자금대출 이자 미계상 | 고정전표 체크 · 누락 (`거래처+계정+적요` 보기에서 항목별로 확인) |
| 전기요금 급증, 시설관리 용역비 인상 | 고정전표 체크 · 금액 변동 |
| 신규 컨설팅 거래처, 신규 카드 가맹점 | 신규 계정패턴 · 신규 거래처 |
| (이력) 7월 통신비 누락 | 고정거래 월별 표의 빨간 셀 |

샘플 파일은 `sample/` 폴더에 있습니다. `python tools/make_sample.py`(openpyxl 필요)로 다시 만들 수 있습니다.

## 주요 기능

| 화면 | 내용 |
|---|---|
| 요약 | 검토월 이슈 건수, 월별 전표·라인·차변 합계, 구성이 같은 전표의 중복 의심 |
| 신규 계정패턴 | 정상패턴 DB에 없는 `거래처 × 계정 × 차/대` 조합. 해당 거래처가 써 온 계정과 비교해 **정상등록 / 이번만 허용 / 이슈**로 판단 (일괄 처리 가능) |
| 고정거래 월별 | 반복거래의 월별 **건수** / **금액** 표. 누락·건수 증가·금액 변동을 색으로 표시하고, 셀을 누르면 해당 라인과 전표 원문 표시 |
| 고정전표 체크 | 거의 매월 발생하는 항목(감가상각·급여·충당금·미수수익 등)의 누락 여부, 전월 대비·이력 중앙값 대비 증감 |
| 패턴DB | 정상패턴과 판단 이력, 고정/제외 지정 항목 관리 |
| 설정 | 반복거래 판정 기준(최소 발생 월수·비율), 금액 변동 허용폭 |

검토 결과는 엑셀로 내보낼 수 있습니다. 시트는 신규계정패턴, 고정전표체크, 월별건수, 월별금액, 중복전표의심입니다.

## 사용 방법

1. **전표 엑셀 불러오기**: 더존 iCUBE 전표출력 엑셀(기표일자·기표번호·계정과목명·거래처명·적요·차변·대변)을 그대로 넣습니다. 과거 이력과 이번 달 파일을 함께 불러와도 되고, 겹치는 라인은 자동으로 제외됩니다.
2. **검토월 선택**: 검토월 이전 전표가 "이력"으로 쓰입니다.
3. **과거 이력으로 정상패턴 수집**: 최초 1회 실행합니다.
4. 신규 계정패턴과 고정전표 체크를 검토합니다.
5. **패턴DB 저장**: JSON 파일로 보관하고, 다음 달에 **패턴DB 열기**로 불러옵니다. Chrome·Edge에서는 한 번 저장 위치를 고르면 이후 변경 사항이 같은 파일에 자동 저장됩니다.

## 판정 로직

- **패턴 키**: `거래처코드(없으면 거래처명) | 계정코드 | 차/대`
- **반복거래**: 이력 개월 수 중 `max(최소 월수, 이력 개월 수 × 최소 비율)` 이상 발생한 항목. 그룹 기준은 `거래처+계정`, 또는 적요까지 묶는 `거래처+계정+적요유형`(적요에서 숫자·괄호를 정규화) 중에서 고릅니다.
- **누락**: 이력의 80% 이상 달에 있던 항목(또는 "고정"으로 지정한 항목)이 검토월에 없음
- **건수 증가(중복 의심)**: 검토월 건수가 이력 최대 건수보다 많음. 또는 평소 1~2건인 항목에서 건수가 늘고 같은 금액이 반복됨
- **금액 변동**: 이력 중앙값 대비 ±허용폭(기본 10%) 초과
- **중복 전표**: 같은 달에 계정·거래처·차대 금액 구성이 완전히 같은 전표가 2건 이상

## 배포 (Vercel)

빌드 과정이 없는 정적 사이트입니다. 이 폴더를 그대로 Vercel에 올리면 됩니다.

- Vercel 대시보드 → **Add New → Project** → 이 폴더를 올리거나 GitHub 저장소로 연결합니다. Framework Preset은 **Other**, Build Command와 Output Directory는 비워 둡니다.
- 또는 CLI를 씁니다: `npx vercel --prod`

```
├── index.html          # 페이지
├── sample/             # 더미 전표 엑셀 (1~11월 이력 / 12월 검토월)
├── tools/make_sample.py  # 더미 데이터 생성 스크립트 (배포 제외)
├── assets/
│   ├── app.js          # 파싱·분석·렌더링 로직
│   ├── style.css       # 스타일 (Pretendard)
│   └── favicon.svg
├── vercel.json         # 보안 헤더(CSP 등)
└── README.md
```
